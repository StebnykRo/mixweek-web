# 05 · Дизайн-система, адаптивність, компоненти

## 1. Дефолтний бренд платформи

Токени з HTML-прототипу (`design/`) стають **дефолтним брендом** —
`Brand{ key: "softswiss-default" }`. Будь-який інший бренд перевизначає їх
повністю. Жодне з цих значень не потрапляє в код компонентів.

```css
/* src/styles/tokens.css — тільки як fallback, реальні значення з БД */
:root {
  --color-bg: #f1f3f7;
  --color-surface: #ffffff;
  --color-ink: #0b0f2b;
  --color-ink-muted: #5a6075;
  --color-divider: #0b0f2b1f;              /* 8-значний hex = ink @ 12% */
  --color-success: #2e9e5b;
  --color-warning: #d99100;
  --color-danger:  #cf3f35;   /* прототипний #d3453b давав 4.48:1 на білому */

  --color-primary-50:#f7f9fe; --color-primary-100:#eef1fe; --color-primary-200:#dbe2fd;
  --color-primary-300:#b6c4fa; --color-primary-400:#8098f7; --color-primary-500:#2b4af0;
  --color-primary-600:#3352ee; --color-primary-700:#2440c9; --color-primary-800:#192e93;
  --color-primary-900:#101e5e;

  --color-secondary-50:#fdfef7;
  --color-secondary-100:#f7fce3; --color-secondary-200:#edf8c4; --color-secondary-300:#def291;
  --color-secondary-400:#cdea5b; --color-secondary-500:#c8f04b; --color-secondary-600:#b4d63c;
  --color-secondary-700:#93b22a; --color-secondary-800:#71891f; --color-secondary-900:#4f6015;

  --color-neutral-50:#ffffff;
  --color-neutral-100:#ffffff; --color-neutral-200:#eef0f5; --color-neutral-300:#dde1ea;
  --color-neutral-400:#bbc2d1; --color-neutral-500:#98a0b3; --color-neutral-600:#787f93;
  --color-neutral-700:#5a6075; --color-neutral-800:#3a3f55; --color-neutral-900:#12162e;

  --radius-sm: 8px; --radius-md: 16px; --radius-lg: 28px; --radius-pill: 999px;

  --font-display: "Caprasimo", Georgia, serif;
  --font-body: "Figtree", system-ui, -apple-system, "Segoe UI", sans-serif;

  --shadow-sm: 0 1px 3px rgb(11 15 43 / 0.10);
  --shadow-md: 0 3px 10px rgb(11 15 43 / 0.12);
  --shadow-lg: 0 12px 32px rgb(11 15 43 / 0.18);
}
```

**Семантика кольору (переноситься на будь-який бренд):**
`primary` — основні дії, обрані чипи, посилання, live-бейджі ·
`neutral-900` — темні акцентні картки, обраний день ·
`secondary` — комерційні CTA (Reserve), FEATURED-бейдж, завжди з темним
текстом · `surface` — картки на фоні `bg`.

Шкала відступів: `4 / 8 / 12 / 16 / 24 / 32 / 48 / 64` (Tailwind-дефолт,
прототипні 4.4/8.8/13.2 округлюються).

## 2. Брейкпоінти й правило адаптації

| Назва | Ширина | Основний шаблон |
|---|---|---|
| `xs` | 0–479 | одна колонка, нижній таб-бар |
| `sm` | 480–767 | одна колонка, ширші картки |
| `md` | 768–1023 | дві колонки контенту, таб-бар → верхня навігація |
| `lg` | 1024–1439 | ліва бічна навігація + контент + права колонка |
| `xl` | 1440+ | те саме, `max-width: 1440px`, центровано |

**Принцип:** мобільний layout — не «звужений десктоп», а базовий. Десктоп
додає *постійно видиму навігацію* і *другу колонку контексту*, а не
розтягує картки на всю ширину.

### Ключові трансформації

| Елемент | Мобільний | Десктоп (`lg+`) |
|---|---|---|
| Навігація | нижній таб-бар, 5 пунктів, safe-area | ліва бічна панель 240px: лого бренду, пункти, перемикач івенту, профіль знизу |
| Home | вертикальний стек | 2 колонки: ліворуч Зараз/Далі, праворуч Оголошення + Featured + швидкі дії |
| Програма | список + горизонтальні чипи днів | 3 колонки: фільтри (фіксовані ліворуч) · список · панель деталей активності (не модалка) |
| Мапа | мапа зверху, деталі знизу | мапа 2/3 ширини + постійна панель місць 1/3 з пошуком |
| Список івентів | вертикальні картки | сітка 2–3 колонки з фільтром зверху |
| Сторінка івенту (минулий) | стек секцій | 2 колонки: контент + бічна колонка «Медіа / Підсумки» |
| WinStyle | сітка 2 колонки | сітка 4 колонки + бічний кошик резерву |
| Профіль | список рядків | 2 колонки: меню розділів ліворуч, вміст праворуч |
| Модалки | bottom sheet (drag-to-close) | центрований діалог max-w 560px |
| Форма реєстрації | покроково, один крок = екран | одна сторінка з секціями + sticky-підсумок праворуч |
| Таблиці адмінки | картки-рядки | справжня таблиця з сортуванням і масовими діями |

### Правила, що не залежать від брейкпоінта
- Мінімальна тач-ціль **44×44 px**.
- Контент ніколи не ховається лише на мобільному «щоб влізло» — або він
  потрібен усім, або нікому.
- Sticky-елементи не перекривають більше 20% висоти вʼюпорта.
- `env(safe-area-inset-*)` для iOS (таб-бар, нижні кнопки).
- Горизонтальний скрол — тільки для чипів днів/категорій, ніде більше.

### 3.3 Стани — обов'язкові для кожного екрана
Кожен екран проєктується у **п'яти** станах: `loading` (скелетони, не
спінер) · `empty` (пояснення + дія) · `error` (що сталося + «Повторити») ·
`offline` (банер «Дані від HH:MM») · `no-access` (для гостей/вимкнених
модулів). Відсутність будь-якого — дефект.

## 4. Доступність (WCAG 2.2 AA — обов'язково)

- Семантичний HTML: `<nav>`, `<main>`, `<header>`, `<h1..h6>` без пропусків.
- Керування з клавіатури для 100% функціоналу; видимий `:focus-visible`
  (2px контур `--color-primary-500`, offset 2px).
- Фокус-пастка в модалках, повернення фокуса на тригер після закриття.
- Контраст ≥ 4.5:1 (текст) / 3:1 (UI). Перевіряється в бренд-редакторі й у
  CI (axe).
- Стан **ніколи** не передається лише кольором: трек-бейдж має текст,
  «збережено» має іконку, помилка — текст.
- `aria-live="polite"` для оновлень «Зараз/Далі» й тостів.
- Анімації вимикаються при `prefers-reduced-motion` (включно з пульсацією
  live-міток).
- Кожне зображення має `alt`; декоративні — `alt=""` + `aria-hidden`.
- Форми: `<label>` для кожного поля, помилки прив'язані `aria-describedby`.
- Мова сторінки `lang` відповідає локалі.
- Тестування: axe в CI (жодних `serious`/`critical`) + ручна перевірка
  VoiceOver (iOS) і NVDA на ключових потоках.

## 5. Типографіка

| Роль | Мобільний | Десктоп | Шрифт |
|---|---|---|---|
| Display XL | 30/34 | 44/48 | display |
| H1 | 26/30 | 32/38 | display |
| H2 | 20/26 | 24/30 | display |
| H3 | 18/24 | 20/26 | body 700 |
| Body | 15/22 | 16/24 | body 400 |
| Body strong | 15/22 | 16/24 | body 600 |
| Caption | 12/16 | 13/18 | body 400 |
| Overline | 11/14, +2px letter-spacing, uppercase | 12/16 | body 700 |

- Мінімальний розмір тексту — 12px. Нижче не використовуємо.
- Шрифти вантажаться з `font-display: swap`, з підмножиною latin+cyrillic,
  preload для body-шрифту, self-host як опція для тенантів з жорсткою CSP.
- Довгі назви обрізаються `line-clamp`, повний текст доступний у деталях.

## 6. Motion

- Тривалості: 120 мс (мікро), 200 мс (перехід), 320 мс (шит/модалка).
- Easing: `cubic-bezier(0.2, 0, 0, 1)`.
- Пульсація live-мітки: opacity 1 → 0.35 → 1, 1.8 с, нескінченно; вимикається
  при `prefers-reduced-motion`.
- Скелетони замість спінерів там, де відомий layout.
- Ніяких «святкових» анімацій, що затримують взаємодію.

## 7. Іконки й зображення

- Іконки — **Lucide**, stroke-width 2, розміри 16/20/24. Імпорт поіменний
  (tree-shaking), не весь пакет.
- Зображення — `next/image`, формати AVIF+WebP, `sizes` обов'язково,
  `priority` лише для обкладинки над згином.
- Плейсхолдери — blurhash або суцільний колір з бренду.
- Зовнішні домени зображень — явний allowlist у `next.config`; довільні URL
  заборонені.

## 8. Темна тема

- Підтримується через `Brand.tokens.mode` і `prefers-color-scheme`.
- У v1 обов'язкова для дефолтного бренду; для кастомних — опційна
  (генерується автоматично з палітри, редагується вручну).
- Перевірка контрасту виконується для обох режимів.

   кольору, радіуси, композиція карток.
